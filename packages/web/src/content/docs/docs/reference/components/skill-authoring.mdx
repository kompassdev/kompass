## Behavior

- grounds changes in project conventions, examples, and observed failures
- defines one reusable job with observable completion criteria
- selects model or user invocation from the modes supported by the project's skill runtime
- writes each model-invoked trigger branch once and uses a human summary for supported user-only skills
- keeps each instruction in one place and moves branch-only detail behind an explicit load condition
- validates invocation frontmatter, completion criteria, references, and relevant scripts or eval helpers
